# Security policy

## Supported version

Security fixes target the latest revision of the `main` branch. Older commits,
forks and locally modified deployments are not maintained by this project.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, private documents or
production logs in a public issue. Use GitHub's private vulnerability reporting
feature when it is available for this repository. If it is unavailable, contact
the maintainer through the repository owner's GitHub profile before sharing
sensitive details.

Include the affected commit, impact, minimal reproduction steps and relevant
request IDs. Use synthetic documents and redacted logs. Never include access
tokens, `.env` contents, storage credentials or personal documents.

This evaluation project does not promise a response-time SLA or claim a formal
security certification. Deployment owners remain responsible for supported
infrastructure, image scanning, TLS, backups, monitoring and incident response.
